# 🏋️ FitLog

<p align="center">
  <img src="./public/fitlog_readme.svg" alt="FitLog Banner" width="900">
</p>
FitLog is a responsive workout tracking web application that helps users discover workouts, create a personal workout plan, and save exercises for later. Users can browse workout information, view workout details, organize their daily plan, and track completed workouts.

## 🚀 Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- REST API
- Browser LocalStorage

## ✨ Key Features

### 1. 🏋️ Workout Library

Browse a collection of workouts with information such as difficulty, equipment, duration, calories, muscle groups, and rating.

### 2. 📋 Personal Workout Plan

Add workouts to today's plan and manage up to five exercises for the day.

### 3. 🔖 Save Workouts

Save workouts for later and access them from the Saved section of the My Plan page.

### 4. 🔍 Workout Details

View detailed workout information including description, muscle groups, equipment, duration, calories, rating, and step-by-step instructions.

### 5. 💾 LocalStorage Persistence

Workout plans and saved workouts are stored in the browser's LocalStorage, so the data remains available after refreshing the page.
